# Atelier 4 — Indicateur de niveau lumineux

## Description
Ce projet IoT utilise un ESP32 et un capteur LDR pour mesurer le niveau lumineux et calculer le pourcentage d'obscurité.

## Matériel utilisé
- ESP32
- Capteur LDR
- 3 LED
- Buzzer
- Bouton poussoir

## Fonctionnalités
- Mesure de la luminosité.
- Affichage de trois niveaux lumineux à l'aide des LED.
- Activation du buzzer au niveau 1.
- Activation et arrêt du système avec un bouton.
- Affichage des informations sur une page Web via Wi-Fi.

## Technologies
- ESP32
- C++ / Arduino
- Wi-Fi et serveur Web HTTP
- Wokwi
